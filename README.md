# HUNTER ARCHIVE

SF 헌터물 세계관 설명 사이트의 정적 프로토타입입니다.

## 구조

- `index.html` — 메인 페이지
- `css/style.css` — 전체 디자인
- `js/main.js` — 부트 화면, 시계, 모달, 인터랙션

## GitHub Pages

1. 이 폴더의 파일을 GitHub repository에 업로드합니다.
2. Repository → **Settings → Pages**
3. Source에서 **Deploy from a branch** 선택
4. `main` / `/ (root)` 선택 후 Save
5. 잠시 기다리면 GitHub Pages 주소가 생성됩니다.

외부 이미지 없이도 작동하도록 제작되어 있습니다. 배경과 초상화는 CSS로 구성되어 있으며, 이후 원하는 이미지로 교체할 수 있습니다.
